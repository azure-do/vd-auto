# contracts — 共通契約（ID・イベント・状態スキーマ）

ADR-0003（Repository分離のまま契約と技術知見を共有する）に基づく、プロジェクト横断で共有する契約の置き場。

## 方針

- ここに置くのは **共通ID・スキーマ・イベント・状態・エラー形式・冪等性規約・署名方式** の契約定義。
- 契約は **バージョン管理** する（ファイル名に `.vN` を付す）。破壊的変更は新バージョンを追加する。
- **所有者**: 本Repositoryの技術責任者（重要変更は亮さんの承認とADR/RFCを経る）。
- **変更通知**: 契約変更時は関連プロジェクト（SEO自動化・講師ポータル・LINE/DM）へ通知する運用とする。
- 秘密値は一切含めない（キー名・構造のみ）。

## 一覧

- `common-ids-events-states.v1.md` — 共通ID / 状態 / 媒体別サブ状態 / イベント / エラー形式 / 冪等性 / 保存ライフサイクル（v1・accepted）

## ステータス

v1は承認済みの基礎契約。破壊的変更は既存v1を書き換えず、新バージョンとして追加し、ADR/RFCで移行条件を記録する。
