## 1. 目的・範囲

- 目的: R2に置いた元動画をYouTubeへ投稿する経路を比較し、方式を決定するための一次情報を得る。
- 範囲: テストGCPプロジェクト・テストチャンネルへの **private 投稿限定**。実支部チャンネル・本番relay・実SNSには接触しない。
- 対象3経路:
  - **A1**: R2 → GAS（URL Fetch）→ Blob → YouTube
  - **A2**: R2 → Driveステージング → GAS → YouTube
  - **B** : R2 → 外部実行環境 → YouTube resumable upload

## 2. 実証環境（秘密はキー名・保存場所のみ）

- YouTube: テストGCPプロジェクト（未監査）＋会社所有の既存テストチャンネル `LRVideoE0ATEST`（公開ハンドル: `@videotest_lr`）。投稿は `privacyStatus=private` 固定。所有Googleアカウントの実メールアドレスはRepositoryへ記載しない。
- ストレージ: Cloudflare R2（テストバケット）。取得は一時資格情報（§5）。
- 認証・秘密: OAuthトークン／client secret／R2一時資格情報／resumable session URI は**秘密**として扱い、本レポート・ログ・スクショに値を記載しない（キー名・保存場所のみ）。
- フィクスチャ: 20MB / 60MB / 300MB クラスのテスト動画（サイズ帯の代表。テスト用途限定）。

### 3.1 不採用理由（根拠区分つき）

- **A1 不採用**
  - 文書化済み制約: Apps Script の URL Fetch 応答サイズ上限（約50MB/回）と実行時間・メモリ上限により、中〜大サイズ動画を1回のFetch/Blobで安全に扱えない。
  - 実測裏付け: `【原文転記待ち／未入手】`（原本のサイズ別成否・所要）。
- **A2 不採用**
  - 構造的コスト: Driveステージングによる往復・二重保管・容量/権限管理・掃除運用が増える。GAS側のBlob/実行制約も残るため、Bの優位を覆さない。
  - 実測裏付け: `【原文転記待ち／未入手】`。
- **B 採用**
  - resumable upload により大サイズ・中断再開・冪等運用に適合。committed offsetからの再送で全量再送を回避。
  - 実測裏付け: `【原文転記待ち／未入手】`（原本のサイズ別所要・再開実績・費用）。

> 結論: 方式=B（ADR-0013）。ただし**外部実行環境の製品は未決**（RFC-0002で比較継続）。上表の数値確定は原本転記が前提。

## 4. YouTube処理結果の判定（実装で採用する定義）

- **完了**: `uploadStatus = processed` かつ `processingStatus = succeeded` かつ `privacyStatus = private` の3条件成立時のみ `PUBLISHED`（private確認込み）とする。
- **処理中**: `processingStatus = processing` の間は `PUBLISHING` 保留・ポーリング継続。
- **失敗**: `uploadStatus = failed` または `processingStatus = failed / terminated` → `FAILED`（`failureReason` を構造化記録）。
- **拒否**: `uploadStatus = rejected`（`rejectionReason`：copyright/duplicate/tos 等）→ 端末的 `FAILED`（自動再投稿しない・要人手確認）。
- **結果不明/期限切れ**: 応答途絶・session期限切れ等で最終結果を確認できない場合は `OUTCOME_UNKNOWN → RECONCILIATION_REQUIRED`（共通契約 3.1〜3.3）。新規セッションを開かず、既存session・video ID・committed offsetで照合する。

## 5. 一時R2トークンの発行・削除・失効（事実記録）

> テスト用トークンの失効は環境保持判断と分離する。失効は後片付けとして独立に実施され、再利用を前提にしない。

- **発行**: 実証時、R2からの取得に用途限定の**一時資格情報**を発行（キー名・保存場所のみ管理、値は非記載）。
- **失効**: 当該一時R2資格情報は**失効済み**（監査で報告された事実として記録）。以後は再利用しない。次に実証・実装する場合は新規に用途限定の一時資格を発行する。
- **削除**: テスト動画・R2オブジェクトの後片付け（削除）は環境保持判断とは別に扱う。
- `【原文転記待ち／未入手】`: 発行/失効の日時、対象キー名、削除実施範囲の詳細（原本から転記）。
- **保持判断との分離**: テストGCPプロジェクト・テストチャンネル自体の保持/削除（監査申請・製品最小実証に使う可能性）は**破壊的操作につき別承認**の別論点であり、トークン失効の可否とは独立に判断する。
