# E-1 local demo

Issue #3は画面ではなく、後続機能が共通利用するバックエンド基盤である。本番接続なしで挙動を確認できるよう、ダミー提出を「受付→検証→承認→YouTube/Instagram処理開始」まで進める実演テストを用意した。

```bash
cd worker
npm ci
npm run demo
```

確認できること:

- 1件の提出が順序どおりに状態遷移する。
- 同じ承認版をYouTubeとInstagramが独立して処理開始できる。
- 媒体と投稿先アカウントごとの二重処理防止記録が作られる。
- 実行者・日時・変更内容の監査記録が残る。
- Google Sheets向けの一方向ミラーイベントが作られる。

使用するのはMiniflare上のローカルD1とダミーIDのみで、Cloudflare実環境、実SNS、実動画、個人情報には接続しない。
