# ダンス動画投稿システム：現行仕様復元書

作成日: 2026-07-27  
対象: Googleフォーム回答、Google Apps Script、外部ライブラリ `VideoUploaderLib`

## 1. 調査結果の要約

- 回答シートは37列で構成されている。
- 2026-01-20から2026-07-22までの2,582件を確認した。
- YouTube投稿成功: 2,569件
- 投稿取りやめ: 11件
- 投稿失敗: 2件
- 同一の動画URLが複数行に登録された例は確認されなかった。
- 外部ライブラリのソースがなくても、入力・生成結果・状態遷移から主要仕様を再実装できる。

投稿成功率は約99.5%であり、現行業務フロー自体は十分に実績がある。新システムではフォームや人間による投稿承認を活かしつつ、外部ライブラリ依存、列番号依存、入力検証不足を解消する。

## 4. 復元できた処理フロー

### フォーム送信時

1. フォーム回答行を取得する。
2. 支部別スタジオ列から、入力されているスタジオを1つ選ぶ。
3. 支部、スタジオ、動画URLを管理列へ転記する。
4. 規定フォーマットでタイトル案を作成する。
5. 曲名、アーティスト名、ジャンル、支部、講師名からハッシュタグを作成する。
6. 支部・スタジオを差し込んだ概要欄を作成する。
7. 支部に対応するYouTubeチャンネルを設定する。
8. 投稿OKと投稿取りやめ用のチェック項目を用意する。

### YouTube投稿時

1. 対象支部の行だけを抽出する。
2. 「投稿OK」が有効な行を抽出する。
3. 投稿済み・投稿取りやめ行を除外する。
4. Driveの動画を対象チャンネルへ投稿する。
5. 投稿日時と結果を記録する。
6. 成功時に動画を所定のDriveフォルダへ移動する。

支部ごとのYouTube認証を使うため、各Googleアカウントが作成した時間主導トリガーから支部別関数を実行していると推定される。

## 5. タイトル生成仕様

基本形式:

```text
【支部】初心者向け{ジャンル}ダンス｜{講師名}先生の{月}/{日}レッスン動画（クラスの雰囲気）
```

確認された問題:

- 希望タイトルが136件入力されているが、最終タイトルは2,582件すべてタイトル案1と同一だった。
- 「タイトル案2」は記録されるだけで、採用処理に使われていない。
- ジャンル自体が「ダンス」で終わる136件では、「女性アイドルダンスダンス」のような二重表現が発生する。

新システムでは以下を明文化する。

- 標準タイトルを使う。
- 希望タイトルを使う。
- AI提案を使う。
- LINE承認画面で選択・編集する。

## 6. ハッシュタグ生成仕様

確認できた現在の基本構成:

```text
#{曲名}
#{曲名}ダンス
#{アーティスト名}
#{アーティスト名}ダンス
#{曲名}カバーダンス

#初心者ダンス
#ダンス初心者
#大人ダンス
#ダンススクールLr
#ダンススクール
#初心者ダンススクール

#{ジャンル}ダンス
#{ジャンル}カバーダンス
#完コピ

#{支部}ダンススクール
#{講師名}
#{支部}初心者向け{ジャンル}ダンスクラス
```

確認された問題:

- 初期データ10件に `{{地名}}` が未置換のまま残っている。
- スペース、全角スペース、`&`、記号などの扱いが一定ではない。
- 自由入力ハッシュタグが `#A#B#C` のまま1つの文字列として追加される場合がある。
- `KPOP`、`K-POP`、`kpop`などの表記揺れがある。
- ジャンルが「ダンス」で終わる場合に「ダンスダンス」が発生する。

新システムでは、表示名とハッシュタグ用文字列を分けて保持する。入力者へ記号除去を要求するのではなく、システム側で安全に正規化する。

## 7. 概要欄生成仕様

概要欄は、支部とスタジオだけを差し替える定型文になっている。主な構成は以下。

- 支部別公式YouTubeチャンネルの案内
- 初心者専門スクールであること
- 対象支部・スタジオ
- 対象年齢
- 60分・90分クラスの説明
- 対応ジャンル
- 視聴・チャンネル登録の案内

新システムでは定型文をコード内に埋め込まず、「投稿文テンプレート」シートまたは設定ファイルで管理する。

## 8. 確認された障害

投稿失敗2件は、Google Drive上の対象ファイルが動画ではなく `image/jpeg` だったことが原因。

現行システムはYouTube APIへ送信するまでMIMEタイプを検証していない。新システムではフォーム受付直後に次を検証する。

- MIMEタイプが動画か
- ファイルが読み取れるか
- 動画の長さ
- 縦横比
- ファイルサイズ
- 投稿済み動画との重複
- 出演許可・楽曲確認

## 10. 外部ライブラリ置換方針

現在確認できている外部インターフェース:

```javascript
VideoUploaderLib.processFormSubmit(e);
VideoUploaderLib.processAllExistingRows();
VideoUploaderLib.uploadVideoByBranch(branchName, YouTube);
```

自社版では、この3機能と同等の入口を最初に実装する。既存フォーム、既存シート、既存トリガーとの互換性を維持した状態でテストし、結果一致を確認してから外部ライブラリを削除する。
