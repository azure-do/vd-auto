# ADR-0007: クラス未確定・マスタ障害時はCLASS_UNRESOLVEDで隔離し投稿へ進めない

## Status

accepted

## Date

2026-07-30

## Context

ADR-0002により、支部・スタジオ・クラス・講師の判定はクラスマスタ（`レッスンマスタ`タブ①/⑤/⑥）を正とする。動画側は参照専用でありマスタを書き換えない。

候補が0件の場合や、マスタ読取障害時に、講師へ支部・クラスを自由入力・自由選択させると、誤った投稿先・誤ったメタデータで公開する事故につながり、ADR-0002を弱める。一方で、提出そのものは止めたくない。

## Decision

- クラスが確定できない場合（候補0件、マスタ読取障害、照合不一致等）は、動画を **受付・保存はするが `CLASS_UNRESOLVED` 状態で隔離** し、承認・投稿へ進めない。
- 障害・未確定は **本部運用グループLINEへ通知** する（基本の通知先。宛先は設定で外部化）。通知内容にPII・秘密値を含めない。
- 講師にその場で支部・クラスを自由選択させない。**本部確認 or マスタ復旧** で解除する。
- 候補が1件なら自動確定、複数件のみ講師にクラスを1回選択させる（選択UIはopen-questions Q7）。
- 参照に用いる read model は正本ではない **派生キャッシュ** とし、`source_version` / `fetched_at` / `TTL` / 差分検知を持つ。

## Consequences

- 誤った投稿先での公開事故を構造的に防げる。
- `CLASS_UNRESOLVED` の解除フロー（本部確認・再判定）と通知運用が設計・受入条件の必須項目となる。
- 代講・振替・休講・臨時クラスは、タブ⑥（状態変更申告ログ）を参照して判定し、確定できないものは隔離側に倒す。
