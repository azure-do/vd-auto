# ADR-0004: GitHubをコードと横断知識の共有基盤として使用する

## Status

accepted

## Date

2026-07-30

## Context

現在のRepositoryはローカルGitのみである。今後は、コードだけでなく、複数プロジェクトの設計判断、共通契約、技術アイデア、横展開候補、採否理由を継続的に共有できる場所が必要である。

## Decision

- Git Repositoryを正式情報源とする。
- 将来のGitHubでは、コード、README、ADR、RFC、共通スキーマ、API・イベント契約、Issue、Project、リリース、変更履歴、セキュリティ方針、横展開候補を管理する。
- 重要な判断はチャットだけで確定せず、ADR等へ記録する。
- 新しい技術アイデアはRFCまたはADR候補として、適用先、導入条件、採用・保留・却下理由を残す。
- GitHubリモート作成、push、公開範囲、アクセス権設定は、亮さんの明示的な承認後に行う。

## Consequences

- 新しい担当者・AIはRepositoryから目的、判断、現状を把握できる。
- チャット間の引継ぎ依存を減らせる。
- GitHub移行前に、Repository構成、権限、公開範囲、秘密管理の計画が必要となる。
