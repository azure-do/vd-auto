# ADR-0001: 現行システムは参考資料であり再現対象としない

## Status

accepted

## Date

2026-07-30

## Context

現行のGoogleフォーム、GAS、外部`VideoUploaderLib`はYouTube投稿で高い運用実績を持つ一方、外部ライブラリ依存、固定列番号、入力検証不足、媒体別状態の欠如、即時公開等の制約がある。

新システムの目的は、現行コードやプロジェクト構成を完全に再現することではなく、講師が動画を1回提出するだけで、動画検証、自動編集、本部承認、YouTube / Instagram / TikTokへの媒体別投稿・再試行までを行える自社基盤を作ることである。

## Decision

- 現行システムは、業務ルール、投稿実績、生成規則、移行比較、失敗事例を抽出するための参考資料とする。
- 現行関数、固定37列、支部別GASラッパ、単一再開状態、文字列ログ、即時公開、外部ライブラリ構造との完全互換を製品要件にしない。
- 互換機能は、新旧並行稼働や段階移行に明確な便益がある場合だけ、一時アダプタとして設計する。
- 新システムの安全性、保守性、拡張性、媒体別状態管理を現行互換より優先する。

## Consequences

- 不明な現行仕様や未提供資料だけを理由に設計を停止しない。
- 現行との差分は、推定・新規設計・テスト可能な受入条件として明示する。
- 現行本番は、新システムの検証とロールバック確認が完了するまで停止・変更しない。
