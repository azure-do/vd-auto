# ADR-0003: Repositoryを分離したままプロジェクト間で契約と技術知見を共有する

## Status

accepted

## Date

2026-07-30

## Context

自社には、SEO自動化、講師ポータル、LINE・DM関連等の複数プロジェクトが存在し、今後も並行して改善される。動画投稿で得られたデータや技術も他プロジェクトで再利用できる一方、既存Repositoryを統合すると責務・デプロイ・所有範囲が曖昧になる。

## Decision

- 各Repositoryとデプロイ責務は分離し、コピー・移動・統合を行わない。
- プロジェクト間で共有する対象は、共通ID、スキーマ、イベント、状態、エラー形式、冪等性規約、認証・署名方式、技術知見とする。
- クラスID、講師ID、支部ID、動画ジョブID、投稿状態、承認状態、媒体別URL等の共通契約をバージョン管理する。
- 表記正規化、SEOテンプレート、ハッシュタグ生成等は、複数プロジェクトで同一責務が確認できた場合に限り共通化を検討する。
- 新しい技術アイデアは、プロジェクト固有か横展開可能かをPMOが分類し、横展開候補として判断材料を提示する。

## Consequences

- 各プロジェクトは独立して変更・デプロイできる。
- 連携には、契約の所有者、バージョニング、互換性、変更通知の運用が必要となる。
- 早すぎる共通ライブラリ化を避け、まず契約と知見を共有する。
