# ADR-0002: 自社クラスマスタを講師・クラス判定の正式情報源とする

## Status

accepted

## Date

2026-07-30

## Context

自社の`レッスンマスタ`には、クラスコード、支部、スタジオ、講師、講師メールアドレス、レッスン時間、状態、曜日・開始時刻の関連データ、状態変更ログが既に存在する。

現行フォームのように、動画投稿側で支部、スタジオ、講師、クラス情報を重複入力・管理すると、表記差、更新漏れ、講師操作の増加を招く。

## Decision

- 自社クラスマスタを、講師、クラス、支部、スタジオ判定の正式な情報源とする。
- 動画投稿システム内に同等の重複マスタを作らない。
- 講師本人とクラスマスタを照合し、当日の担当候補が1件なら自動確定、複数件の場合だけ講師へ選択を求める設計を目標とする。
- 動画投稿側はクラスマスタを参照するが、独自判断で書き換えない。
- 代講、振替、休講、臨時クラス、同期・キャッシュ・障害時の扱いは設計と受入条件で明示する。

## Consequences

- 通常時の講師操作を動画選択と提出だけに近づけられる。
- マスタの所有者、同期方式、キャッシュ期限、障害時フォールバックが設計上の必須事項となる。
- Googleフォームを一時利用する場合も、入力値ではなくクラスマスタを正として検証する。
