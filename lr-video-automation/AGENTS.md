# AI作業入口

外部委託者とそのAIは、**このリポジトリだけで作業を開始できる**。別の非公開リポジトリへのアクセスは前提にしない。

作業開始前に、次の順で読む。

1. 対象のGitHub Issue
2. このリポジトリの `README.md`
3. `CLAUDE.md`
4. IssueとREADMEが指定する `docs/`

役割・権限・停止点は `README.md` と
`docs/runbooks/external-contributor-delivery.md`、情報管理は `CLAUDE.md` を正本とする。

社内PMO・監査として作業し、ローカルに `../ai-governance/` が存在する場合だけ、横断規約も追加で読む。アクセス権がない外部委託者とそのAIは、`ai-governance` を探したりアクセス申請したりせず、本リポジトリの規約だけで続行する。
